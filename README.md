# Trainz Railroad Simulator 2022 Enc Manager

加密模组专用管理器 —— 为 Trainz Railroad Simulator 2022 的受保护模组（定制包）提供安装、启用、启动和卸载的一站式管理。

## 这个软件是什么

一个 Windows 桌面程序。模组作者把加密后的定制包（`.baieiiie` 文件）发给用户，用户用这个管理器导入、勾选、一键启动游戏。管理器会在游戏启动前自动完成解密部署，游戏退出后自动清理。

## 我为什么要做这个软件

TRS2022 的模组生态里，作者花几百小时做的模型、贴图、配置，发出去就是裸文件——谁拿到谁用，没有署名，没有授权，没有回报。这个管理器让模组作者能把作品加密后按用户发放，只有拿到授权包的人才能在游戏里使用。

## 特性

- 毛玻璃双主题界面（日间暖调 / 夜间极客黑），自动跟随系统时间切换
- 多语言：中文 / English / Русский，实时切换
- 一键启动游戏，自动完成部署和清理
- 模组库管理：导入、启用/禁用、删除、外来包识别
- 机器码生成（用于作者发放授权）
- 管理器内置检查更新，自动提醒新版本
